### 为什么选这本

1. **中国早教视角缺口** — Karp(美国安抚)+ AAP(美国权威医学)都缺中文早期教育操作
2. **0-3 岁全覆盖** — PART 1 (0-1 岁) + PART 2 (1-2 岁) + PART 3 (2-3 岁),首次扩到 S6/S7
3. **早教类内容** — 重点是月龄发育里程碑 + 早教操作(教察言观色 / 学小勺 / 教指挥),与 AAP 安全/喂养互补
4. **中文家长接受度高** — 鲍秀兰是国内权威,验收阻力小
5. **OCR 可读** — 已转 .md,跳过 OCR 工程,直接进章节地图 + 提取

### ⚠️ 这本书 vs 任务原写崔玉涛(2026-05-02 切换)

任务原描述假设的"中医 / 中国疫苗 / 月子习俗 / 中美差异"在鲍秀兰**不会有**。鲍秀兰是早教派不是临床派,对应的术语扩展方向变成:

- **月龄发育里程碑术语**(大动作/精细动作/认知/语言/社会交往/自理能力 6 维)
- **早教操作术语**(教察言观色 / 教点头摇头 / 教指挥 / 教坐盆 / 学小勺 / 玩娃娃模仿 等)
- **跨年龄段教育连续性概念**(1-3 岁的学习能力培养)

### 4.2 提取策略

**对每段**(S1 → S7 顺序,**按书顺序**):

## 9. OCR 已知噪声模式(供提取时纠正)

样本扫描发现:
- 字间空格断裂:"鲍 秀 兰" / "婴 幼儿" / "潜能 开发" → 还原为连写
- 数字字符化:"20年5 1月" → "2016 年 5 月","6 1次" → "第 1 次"
- 标点错位:"” → 应位 引号位置
- 表格化噪声:很多 markdown table 标记 `|` 实为 OCR 误识,可忽略
- 月龄写法多样:"1 月龄" / "1 月 龄" / "1 个月" 都指同一概念
- 引号方向乱:" " " 混用
- 字符替换:"贞幼儿" → "婴幼儿","洲能" → "潜能","Off" → "0-1 岁"

提取时按上下文还原,标 `[OCR 修正:X→Y]`。
