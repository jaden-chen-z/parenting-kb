- 2 张卡(C-S1-190 + C-S2-132)误把 Karp 哭闹回应卡引为 C-S1-005

- **教训**:写卡时不能凭印象写 ID,要查实际卡号

### 意外 2:hook 字数超 12 chars(英文 + 数字撑爆)
- 蒙氏术语 topponcino / parentese / floor bed / playpen 等英文词单字符多
- 实测 13 处 hook 因含英文长词超 12 字符
- **修复**:全部缩短或换中文表达
- **教训**:hook 优先中文 + 短英文(< 6 字符)

### 意外 3:title 字数超 15 chars
- 5 张卡 title 含数字范围 + 英文(如 "12-15 月转 toddler bed" 20 字)
- **修复**:简化("12-15 月转矮床" 11 字)
- **教训**:title 写出来后立即 Python len() 检查

### 意外 4:学究词残留 23 处
- 高频:阶段(后期保留为非学究)/ 协调 / 认知 / 感知 / 机制 / 本质 / 分化 / 情绪劫持
- **修复**:全部换白话
  - 协调 → 配合 / 一起做 / 手脚配合
  - 认知 → 大脑工作 / 学 / 想 / 练脑
  - 机制 → 是怎么回事 / 为什么 / 做法
  - 感知 → 感觉 / 察觉
  - 本质 → 关键 / 真正
  - 分化 → 变化 / 分开
  - 情绪劫持 → 被情绪带跑
- **教训**:Python 学究词扫描必须每次跑一遍,人工评估 + 改
