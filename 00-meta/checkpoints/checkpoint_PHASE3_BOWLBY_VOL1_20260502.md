### 3.3 工程意外

**意外 1:YAML alias 陷阱**(发现并修复)
- 列表项以 `- **xxx**` 开头时,YAML 把 `*` 解析为 anchor reference,报错"while scanning an alias"
- 影响 14 张卡(S2, S3, S4, S5, S6 多处)
- **修复**:正则替换 `^(    - )\*\*([^*]+)\*\*` → `\1\2`,移除列表项首位的 `**` markdown 加粗
- **教训**:列表项不要以 `**` 开头,markdown 加粗只能用在中文行内

**意外 2:string 中冒号 `:` 引发 mapping value 错误**(发现并修复)
- `external: Bowlby (1973) Attachment and Loss Vol 2: Separation` 中的冒号让 YAML 误解
- 影响 2 张 glossary 卡(G-PERSON-Ainsworth + G-TERM-internal-working-model)
- **修复**:用双引号包裹整个字符串
- **教训**:外部引用如有冒号,必须加引号

**意外 3:子列表缩进问题**(发现并修复)
- C-S5-071 中的 `1. xxx 2. yyy 3. zzz` 数字子列表导致 YAML scanner 报错
- **修复**:改成 inline 单行(`5 项: A / B / C / D / E`)+ 引用 C-S4-071 详细版
