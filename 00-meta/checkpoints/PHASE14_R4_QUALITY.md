### 维度 1:白话风格(PHASE1 §2.5)

**合格率:42/47 = 89%**

✅ **优秀样本**:

### 维度 6:citation 准确性 / 一致性

**合格率:30/47 = 64%** ⚠️ **最严重维度**

❌ **作者列表不一致**(P0):
书库中海蒂卡有两组作者写法,**两套并存**:
- **3 作者版**(36 张):`Heidi Murkoff` / `Sandee Hathaway` / `Arlene Eisenberg`,year `1989`,`year_2nd_ed: 2010`,`year_zh: 2014`
- **2 作者版**(11 张):`Heidi Murkoff` / `Sharon Mazel`,`year: 2010` 或 `1989`,`edition: 3rd (2014)` 或 `Third Edition`

**事实核对**:
- 1989 第 1 版作者 = Arlene Eisenberg + Heidi Murkoff + Sandee Hathaway(三作者)
- 2010 第 3 版作者 = Heidi Murkoff + Sharon Mazel(Sharon Mazel 取代了过世的 Eisenberg / 退休的 Hathaway)
- 用户基线"2014 中译本第 2 版"实际对应英文 **3rd Ed (2010)**,中译者 **莫夏迪/张敏**
- 因此 **2 作者版(Murkoff + Mazel)是正确的**,3 作者版引用了 1989 初版的作者,与 2014 中译本不符

**严重性**:36 张卡片(占 76%)的作者列表错误。

❌ **publisher_zh 不一致**(P1):
- 一组:"南海出版公司(新经典发行)" — 全名
- 另一组:"南海出版公司" — 简写
- 第三组:"南海出版公司(中译)" — 加注
- **应统一为 "南海出版公司(新经典发行)"**(完整版)

❌ **edition / year_2nd_ed 字段混乱**(P1):
- 2 作者版有的写 `edition: "Third Edition"`,有的写 `edition: 3rd (2014)`,有的同时给 `year_2nd_ed: 2010` + `edition: "3rd"`
- 字段名应统一(用 `year_3rd_ed: 2010` 或 `edition: "3rd Edition"` 二选一)

⚠️ **location 章节页码合理性**:
- 大多合理,但 C-S1-2202 location 写 "页 147-148, 194-195" — **中译本 0-1 岁卷正文不到 750 页,194 + 147 跨章节正常**
- C-S5-2247 location "542 页中译" — 看起来合理(在第 18 章范围内)
- C-S0-2400 location "第二版前言 + 第 2 章 婴儿装备" — **"第二版前言"模糊**,2014 中译本对应英文 3rd Ed,前言是"3rd Edition Introduction"

✅ 没发现"第 99 章 页 9999"这类荒诞页码。

❌ **C-S3-2247 source_id 加引号** `source_id: "SRC-040"` 而其他卡片不加 — **格式不一致**(P2)。
