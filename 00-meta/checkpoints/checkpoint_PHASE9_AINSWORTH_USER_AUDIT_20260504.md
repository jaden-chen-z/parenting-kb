## 2. 三审补 5 张知识卡详情

### 2.1 C-S0-519 回乡分娩 16-23 周窗(§17)⭐ B 级

**重要度**:中国春运抱娃高频痛点 — "32 周后赶高铁/飞机"早产风险陡增。
**核心**:松田硬窗 16-23 周;原医院 + 故乡医院联络 ≠ "拿介绍证明就接受"。
**跨源**:↔ Brazelton C-S0-001 触点孕 7 月产检 + 自卷 C-S0-368 父亲进核心家庭 + Brazelton C-S0-005 上班妈母乳。

### 2.2 C-S1-764 产后 40 天就可孕(§43)⭐⭐ A 级

**重要度**:中国"月子病" + 避孕焦虑;"没月经不会怀孕"是普遍误解。
**核心**:松田硬数字 — 产后 40 天母体开始排卵,可能怀孕(没月经也算!);子宫 5-6 周回缩;阴道分泌物 3-6 周消(不必跑医院"治疗")。
**跨源**:↔ Karp C-S1-033 产后抑郁 3 阶段 + Brazelton C-S0-001 触点 + 鲍秀兰 C-S1-068 新生儿 4 大禁忌。

### 2.3 C-S3-705 4 月加果汁不强求(§97)⭐ B 级

**重要度**:中国家长被"4 月起必须加果汁"焦虑误导,松田立场:加不加由娃定。
**核心**:母乳含维 C → 母乳娃完全不必加;奶粉娃复合维生素也够;但加可练奶嘴 + 缓解便秘 + 让娃尝甜味。
**跨源**:↔ 自卷 C-S3-552 4 月前不加任何辅食 + AAP C-S3-001 辅食准备 4-6 月 + AAP C-S3-002 过敏食物 4-6 月引入。

### 2.4 C-S7-760 噩梦 vs 夜惊不一样(§449)⭐ A 级

**重要度**:中国家长高频痛点 — 娃做噩梦后慌乱叫醒 / 跑医院开药。
**核心**:松田区分两类 — 3-4 岁噩梦(可记住)vs 5-10 岁夜惊症(深睡发生记不住)+ 妈抱紧说"妈在这,别害怕" + 反白天看恐怖电视 + 反医生开抗癫痫药。
**跨源**:↔ Lansbury C-S6-406 0-2 岁不看 TV + Bowlby V1 C-S5-070 12 月安全依恋 + 自卷 C-S7-759 反"自体中毒"标签。

### 2.5 C-S7-761 反"哮喘发作"娇惯出(§445)⭐ B 级

**重要度**:松田尖锐立场 — 大人围着孩子捶背擦痰才叫"发作",是父母把孩子推上"皇帝位"。
**核心**:用"这点痰没什么"轻松态度 → 让娃懂"自己痰自己咳"。3-4 岁不养自主,5-6 岁哮喘越严重。
**跨源**:↔ 自卷 C-S7-759 反"自体中毒"标签(同源:反过度医疗化)+ Lansbury C-S6-403 限度+情绪并存 + Brazelton C-S7-016 2 岁三件大事。

## 3. 三审补 2 张术语详情

### 3.1 G-TERM-jaundice-types ⭐⭐(13 次出现)

**重要度**:新生儿黄疸是高频医学事件,中国家长容易"等等就好"延误胆道闭锁(1 月内手术 vs 后续要换肝)。
**核心**:3 类区分(生理性 7-10 天消 / 母乳性 1-2 月 / 病理性需查);**大便白色 = 胆道闭锁警戒**。
**跨派**:松田 §72 §88 + AAP 黄疸看皮肤蔓延范围 + AAP 2022 Hyperbilirubinemia Guideline。
**related**:C-S1-613 黄疸不消退要警戒 / C-S1-091 (AAP 黄疸看皮肤蔓延)/ C-S1-612 未成熟儿出院。

### 3.2 G-TERM-physical-punishment ⭐⭐⭐(4 次跨多卡)

**重要度**:体罚是中国家长高频争议(棍棒底下出孝子 vs 现代育儿全面反对),松田/Lansbury/Bowlby/蒙氏 5 派共识反体罚。
**核心**:1.5-2 岁娃看到体罚就怕 + 受虐儿童紊乱型依恋(D 类)风险 + WHO 2018 全球禁止体罚立场 + 替代工具(承认情绪 + 限度并存 + 离开冷静 + 自我反思)。
**跨派**:松田 §360 + Lansbury "I won't let you" + Bowlby V1 §18 受虐 + Lillard No 永远是 No + Davies 温柔边界。
**related**:C-S6-671 1 岁后看体罚会怕 / C-S7-758 自慰是常见的(反打骂)/ C-S6-403 限度+情绪并存 / C-S2-132 哭闹 5 步回应法 / C-S2-128 等 3 秒再回应。
