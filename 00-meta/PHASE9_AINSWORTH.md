## 8. 工程意外 + 教训

### 8.1 Pikler PDF 是德文原版
任务书 fallback (b) 写"Pikler 英译《Peaceful Babies — Contented Mothers》",但实际 OCR 是 `pikler_friedliche_babys.md`(德文原版 `Friedliche Babys — zufriedene Mütter`)。德文不能直接产中文卡,fallback (b) 路径堵。
**教训**:fallback 列表的"英译版"前提要校对。

### 8.2 G-PERSON-Matsuda 已被并行 session 创建
我尝试 Write 时报错 "File has not been read yet"。Read 后发现已存在(并行 session 创建,引 SRC-024 + 占位 cards)。Edit 修复 SRC-024 → SRC-023 + 占位 cards → 实际写的代表 ID。

### 8.3 G-TERM-air-bath 也已并行存在
同上,Edit 加 SRC-023 references。

### 8.4 YAML 块标量符号 `>` 触发 parse 错
C-S2-701 写"- > 120 减奶量比标识少",`>` 是 YAML 块标量起始符。Edit 改"- 超 120 千卡就减奶量"。
**教训**:列表项不能以 `>` 开头(以及 `|`、`!`、`*` 等保留符号)。

### 8.5 段 ID 实时变化(并行 session 写)
启动时各段 max ID(317/559/496/501/500/598/616/554),写完 38 张后再扫 max ID 已涨到(518/762/700/704/704/803/826/757)— 并行 session 写 SRC-024 +200 buffer 用了大量 ID。新加 5 张用 +N 增量(701/763/758)避撞。
