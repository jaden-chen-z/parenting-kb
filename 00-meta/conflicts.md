- **Chess-Thomas(Lerner V3 Ch 3 historical)**:9 维度 — 1956 经典,临床细分
- **Brazelton(SRC-010)**:高敏儿童群体描述 — 临床实操
- **Kagan(Lerner V3 Ch 4)**:抑制型 18% + 非抑制型 25% — 生物两类
- **处理**:4 派各取所需。家长用 Rothbart 3 维度日常评估;临床用 Chess-Thomas 9 维度;Brazelton 高敏指南落地;Kagan 抑制型有特殊养育策略。无真冲突,是不同抽象层级。

### G3 父母教养类型(Maccoby-Baumrind 4 类型) vs RIE / 蒙氏

- **Baumrind + Maccoby(Lerner V3 Ch 8)**:权威型(高要求 + 高回应)最优
- **RIE Lansbury / Gerber(SRC-019/021/022)**:尊重 + 信任(强 = 高回应,弱 = 低控制)
- **Lillard 蒙氏(SRC-016)**:自由 + 限度(类似权威但更结构化)
- **Pikler(SRC-026)**:尊重发展 + 不干预
- **处理**:Lerner 综述权威型 = RIE 高回应/低强迫的实证后台。无真冲突,是不同表达。中国家长 = "严而暖"概念支持。

### G4 攻击认知派(Dodge) vs 关系派(Lansbury)

- **Dodge(Lerner V3 Ch 12)**:攻击儿童是 6 步信息处理认知偏差(解读偏 + 目标偏)— 认知干预
- **Patterson(Ch 12)**:攻击是亲子互动训练出来的强制循环 — 行为改变
- **Lansbury(SRC-019)**:不打不咬 = sportscasting + acknowledging — 关系修复
- **Gerber(SRC-021/022)**:Antaeus tantrum + 红黄绿限度
- **处理**:3 派互补不是对立。Dodge 给认知地图,Patterson 给互动循环理论,RIE 给关系修复实操。中国家长综合 — 教情绪用词(RIE)+ 改解读偏差(Dodge 长期)+ 不强制循环(Patterson)。

### G5 道德发展(Kohlberg / Turiel / Smetana) vs 鲍秀兰道德启蒙 vs Lillard 服从

- **Kohlberg(Lerner V3 Ch 13 historical)**:3 水平 6 阶段经典
- **Turiel + Smetana(Ch 13)**:4 类规则(道德/习俗/个人/谨慎)— 反 Kohlberg 单线
- **Killen(Ch 13)**:5 岁就有偏见,5-7 岁是预防关键期
- **鲍秀兰(SRC-009)**:道德启蒙临床版
- **Lillard(SRC-016)**:服从 3 阶段
- **处理**:Turiel 4 类规则是综述新共识,代替单线 Kohlberg。中国家长用 4 类规则区分管教法 — 道德规则(打人)硬禁,习俗规则(吃饭)解释,个人规则(穿啥)放手,谨慎规则(摸火)护安全。

### G6 反"反抗期"(松田) vs 支持自主斗争期(Erikson + Lerner)

- **松田道雄(SRC-024 §455)**:反"反抗期"是大人剥夺玩出来的,生理无反抗期
- **Erikson(via Lerner V3 Ch 1)**:1-3 岁 autonomy vs shame 是必要发展冲突
- **Lerner V3 Ch 5 Saarni**:tantrum 是 PFC 没装好,不是不听话(支持斗争期生理性)
- **处理**:松田立场跟 Lerner 综述真冲突。Lerner 综述支持 1-3 岁 autonomy 期是必经,松田认为是大人剥夺玩制造的。中国家长 — Lerner 综述权威更稳,松田哲学补充(玩自由很重要)。

### G7 文化 self(Markus 互依 vs 独立) + 跨文化育儿(Bornstein) vs 主流美式育儿

- **Markus(Lerner V3 Ch 9)**:东亚 互依 self vs 美国 独立 self,不是次等是不同
- **Bornstein(Lerner V3 Ch 8)**:不同文化早期互动模式差大,各自结果都健康
- **Rogoff(Ch 7)**:墨西哥/危地马拉 intent participation 学习深度大于课堂
- **Parke-Buriel(Ch 8)**:80% 美国研究是白人中产,其他文化教养标准不同
- **主流美式育儿书(AAP/Brazelton/Karp/Lansbury)**:基于美国白人中产假设
- **处理**:中国家长不必照搬美式 self-esteem / 早期独立训练标准。中国传统 多人养 / 共睡 / 严而暖 跟非洲 / 日本 / 拉美类似,有结果验证,不是落后。

## H — Phase 11 Lerner V2《Handbook of Child Psychology Vol 2》(2026-05-04)

### H1 Cohen-Cashon 经验派 vs Spelke 先天派(Ch 5 内部)

- **Cohen-Cashon(SRC-028 Ch 5 主笔)**:Constructivist Information-Processing 派
  - 习惯化测"区分"不一定测"概念"
  - 4 月物体永久"看似"先天可能是快速学习产物
  - 信息处理模型可解释 = 不需要先天模块
- **Spelke(核心知识 5 系统派)**:婴儿出生即有 5 个先天结构化系统
  - 物体 / 行动 / 数 / 空间 / 社会
  - Baillargeon 吊桥 + Wynn 5 月加法是硬证
- **Karmiloff-Smith(神经建构主义)**:基因 + 经验 + 时间 = 模块逐渐建成
- **处理**:V2 综述给 3 派立场对照,辩论持续。中国家长 — 不要听"婴儿是 X"的单一立场,综述权威态度多元。互动陪伴是各派共识。

### H2 Werker reorganization vs Kuhl 失能立场(母语音素窗口)

- **Werker/Logan 1985(SRC-028 Ch 2)**:6-12 月母语音素重组 = 注意力重组,不是失去能力
  - 强制注意条件下仍能辨外语音素
  - "专家化",不是"丢能力"
- **Kuhl(部分立场)**:perceptual narrowing = phoneme discrimination 能力下降
- **处理**:V2 现代综述倾向 Werker 立场(reorganization)。中国家长意义 — 6 月后学外语不是"过窗口",是更费力但仍可学。双语 0-12 月最优窗口。

### H3 Carey 概念革命 vs Piaget 渐进阶段

- **Carey 1985(SRC-028 Ch 14/16)**:概念发展不是渐变是革命(范式转移类似 Kuhn 科学史)
  - 4 岁认为植物不是活物,7-10 岁革命
  - 不是"加细节",是分类系统重组
- **Piaget(经典派)**:4 大认知阶段渐进
- **Gopnik(SRC-015)**:孩子是科学家 — 跟 Carey 同方向
- **处理**:V2 综述支持 Carey 立场(2006 主流)。中国家长 — 4 岁孩子"不科学说法"(植物不是活)是常态,不要急纠正,讨论 + 困惑制造比直接教更有效。

### H4 Karmiloff-Smith 神经建构 vs Pinker 强先天派

- **Karmiloff-Smith 1992-2009(SRC-028 Ch 1/14)**:神经建构主义
  - 基因不直接对应"认知模块"
  - Williams 综合征 + SLI 实证 — 早期微小差异 → 累积 → 看似模块
  - 反 Pinker 强先天派 + 反 Spelke 完全先天
- **Pinker(强先天派)**:语言 + 数 + ToM 模块出生即有
- **Spelke(部分先天派)**:5 系统先天但非模块化
- **处理**:V2 综述当代主流是神经建构主义(2006)。中国家长意义 — 基因测试不能预测能力,早期干预对疾病有效因为模块在建中。"基因好就放松"是错。

### H5 Mandler 知觉 vs 概念范畴 vs Quinn 知觉先于概念

- **Mandler 1992-2004(SRC-028 Ch 16)**:知觉范畴 ≠ 概念范畴(独立系统)
  - 7-9 月已有知觉范畴
  - 12-18 月独立概念范畴(动物 vs 工具)
  - 24-36 月稳定区分两类
- **Quinn(经典立场)**:概念范畴基于知觉相似累积
- **处理**:V2 综述微倾 Mandler。中国家长意义 — 24+ 月教多分类(不只外形 / 颜色),教按功能分(吃的一堆 / 玩的一堆),不只按知觉。

### H6 中国孩子数学早起步 vs"中国孩子数学天赋"流行说法

- **Geary 综述(SRC-028 Ch 18)**:跨文化数学发展实证
  - 中文数词更短 + 规则 → 工作记忆容量优势
  - 4 岁中国孩数到 50,美国孩 30 — 语言原因
  - 数感(Spelke 数系统)跨文化一致
- **流行说法**:中国孩子数学有天赋
- **处理**:V2 综述明确 — 不是天赋,是中文数词系统的认知优势。中国家长意义 — 不必"加速"训练(已有自然优势),数感(approximate number)跨文化一致,不要拿"早会数 100"证明智力高。美国孩子概念后期赶上。

### H7 Adolph 大动作实证派 vs 中国"早走 = 健康"流行说法

- **Adolph 2003+(SRC-028 Ch 4)**:学走精细数据
  - 1500-9000 步/天 + 17 跌/小时 = 完全正常
  - 学步车跳过爬行 → 视觉悬崖反应延迟(Bertenthal)
  - 跨情境运动不迁移 — 走斜坡不会自动走桥
- **Pikler(SRC-026)**:不教翻坐爬站走 — 哲学版
- **流行说法**:学步车帮助学走 + 9 月不走是落后
- **处理**:V2 + Pikler 立场一致 — 反学步车 + 反"早走焦虑"。中国家长意义 — 跌 17 次/小时是正常学习量,不要给学步车,不焦虑"几月学会走"(范围 9-18 月)。

## I 节 · Phase 12 Lerner V4 SRC-029 应用层综述立场对照(7 项)

> Lerner V4《Child Psychology in Practice》(Wiley 2006 6th ed,Renninger-Sigel 主编)24 章 80 张知识卡。
> 本卷是应用层综述,跟铁三角 V3 V2 + 临床派 + 哲学派全方位对接,7 大立场对立。

### I1 Hyson DAP 反学业前移 vs 中国"3 岁起跑线"流行

- **Hyson-Copple-Jones(SRC-029 Ch 1)**:DAP 4 原则
  - 基于发展知识 / 个体差异 / 文化语境 / 学习领域
  - 反 5 岁练写字 / 4 岁认 100 词 / 3 岁报班
  - 学业前移**没有研究证据支持**(Bredekamp-Copple)
  - 真正预测后期学业:**自调节 + 词汇 + 兴趣**
- **流行说法**:3 岁起跑线 + 5 岁不识字就晚
- **处理**:V4 + Hyson + Lansbury(SRC-019)+ 松田(SRC-024 §470)立场一致。中国家长意义 — 5 岁前别教写字,玩+互动+读 = 真早教,反"起跑线"焦虑。

### I2 Bornstein 文化特异性 vs 美式育儿普世化

- **Bornstein(SRC-029 Ch 22)**:育儿科学综述权威立场
  - **没有"全球最优育儿法"**
  - 50+ 跨文化研究证明文化特异性
  - 美中产价值观:独立 / 早睡 / 个性
  - 集体文化价值观:互依 / 同睡 / 服从
  - 都健康都成功
- **流行说法**:美式专家说就对 / 美国研究普世适用
- **处理**:V4 + Greenfield(Ch 17 SRC-029)+ 松田(SRC-024)+ 鲍秀兰(SRC-009)立场一致 — 反美式普世化。中国家长意义 — 不必崇美式 / 不必弃中式,接受多种文化都健康。

### I3 Powell 系统化干预 vs RIE 不打扰立场

- **Powell-Ramey(SRC-029 Ch 14 + Ch 21)**:系统化早期干预 RCT 派
  - NFP / Head Start / Abecedarian / Triple P / Incredible Years / PCIT 等 8 大 RCT 项目
  - 高风险家庭主动介入 + 持续 6+ 月 + 关系导向
  - **早 + 强 + 持** = 35 年长效(Abecedarian)
- **RIE(Lansbury SRC-019 + Gerber SRC-021/022 + Pikler SRC-026)**:不打扰 + 慢节奏
  - 婴儿是有能力的主动者 — 别干预
  - 反"系统化"早教课程
  - 跟随发展节奏
- **处理**:不判对错。**适用场景不同** — 高风险家庭 RCT 项目有效,普通家 RIE 哲学健康。中国家长意义 — 普通家 RIE 哲学(不打扰 + 高质量陪伴),高风险家(单亲 / 移民 / 低收入)主动找干预项目。

### I4 Cicchetti 情感虐待神经层冲击 vs 中国"冷暴力没事"传统

- **Cicchetti-Toth(SRC-029 Ch 13)**:发展精神病理学综述
  - 4 类型 maltreatment 全部冲击神经发育(海马 + PFC + 杏仁 + HPA)
  - **情感虐待和身体虐待一样伤娃**(神经层不分类型)
  - 50% 心理健康问题 + 30% 学业问题
  - 但 30% 韧性 — 早干预 60% 改概率
- **中国传统**:"没动手不算虐待" / "骂几句没事" / "娃皮实"
- **处理**:V4 + V3 Patterson(C-S6-1075)+ Shonkoff cortisol(C-S2-806)立场一致 — 情感虐待 = 神经层冲击。中国家长意义 — 没打不代表没虐待,冷暴力 / 贬低也伤神经。

### I5 Comstock 媒体禁屏 vs 中国 iPad 普及

- **Comstock-Scharrer(SRC-029 Ch 20)**:媒体 5 大效应元分析
  - 暴力 / 性别刻板 / 广告 / 学业排挤 / 社会化
  - 0-2 岁绝对禁,2-6 岁限优质内容
  - **"教育屏幕"也踩 5 大效应**(短视频教育 = 社会化短视频规则)
  - 父母看屏 → 跟娃互动减少
- **中国流行**:iPad 当电子保姆 / 教育 app 18 月 OK / 短视频"教育"
- **处理**:V4 + AAP(SRC-002)+ 松田 §428(SRC-024)+ Lansbury(SRC-019)立场一致 — 反屏。中国家长意义 — 0-2 岁绝对禁,2-6 岁限 1 小时优质,父母先放手机。

### I6 Greenfield 文化路径 5 维度 vs"美式独立才现代"立场

- **Greenfield(SRC-029 Ch 17)**:文化路径 5 维度
  - 自我 / 依恋 / 教养 / 道德 / 学习
  - 独立 vs 互依 — **两端都健康**
  - 反"美式独立 = 现代 / 中式服从 = 落后"
  - 移民家培养 **biculturalism**(双文化能力)
- **流行说法**:美式独立才科学 / 中式包办落后
- **处理**:V4 + Bornstein(C-S0-1231)+ 松田(SRC-024)立场一致 — 文化路径都健康。中国家长意义 — 互依不是落后,服从不等于压抑,移民家娃可双文化。

### I7 Lamb 托育 quality > quantity vs"全职妈才好"流行

- **Lamb-Ahnert(SRC-029 Ch 23)**:托育综述权威立场
  - **质量决定不身份决定**

  - 互依 self ≠ 独立 self 初级阶段

### J6 lifespan vs critical period(Baltes 反早期决定论 + 反 0-3 关键期论)

  - plasticity 持续到 70+ 岁
  - SOC 模型 — 一辈子 3 大策略
  - 真正关键期很少(视觉 / 母语暴露 / 依恋)— 多数是敏感期可补救

- **涉及卡片**:C-S0-1513, C-S0-1514, C-S0-1515, C-S0-1516, C-S0-1517, C-S6-1503, C-S8-1135

### J7 PYD asset-based vs deficit-based(Lerner PYD 反修补缺点)

- **Lerner / Benson / Scales / Hamilton / Sesma(SRC-030 Ch 16)= PYD 5C(后扩 6C)**:
  - Competence / Confidence / Connection / Character / Caring(+ Contribution)

- **中国 "成绩中心 / 修补缺点" 立场 = deficit-based**
- **Brazelton(SRC-010)touchpoints 立场 = 部分 asset 倾向**(看孩子能力)

- **涉及卡片**:C-S0-1522, C-S6-1505, C-S7-1602, C-S7-1607, C-S7-1608, C-S7-1609, C-S8-1136, C-S8-1145

### J8 intrinsic motivation vs extrinsic reward(Csikszentmihalyi flow 反奖励驱动)

- **Csikszentmihalyi(SRC-030 Ch 9)= flow theory**:
  - 内在动机 > 外部奖励
  - autotelic 人格 — 为做而做
  - 挑战/技能匹配是 flow 必要条件
- **行为派 / 中国传统 "奖励 + 表扬" = extrinsic reward 立场**

### J9 反抗期 vs intentional self-development(Brandtstädter 视角解松田反"反抗期")

  - 2-3 岁"我自己 / 我要"是 intentional self-development 起步

  - assimilation(改环境)+ accommodation(改自己)双策略
- **松田(SRC-024)= 反"反抗期"立场对接**(玩自由不被剥夺则无反抗期)

### J10 systems thinking vs linear thinking(系统观批判线性思维)

- **跨章共识(SRC-030 Ch 6 + 8 + 14 + 15)= systems thinking**:
  - 整体 ≠ 组件之和
  - multi-feedback 不只单线 cause-effect
  - reductionism 还原论被反对

- **处理**:V1 综述明确反 reductionism + 反线性思维。中国父母 — 任何决定想 3+ 反馈环路,不只单线 cause-effect。

  - linked lives — 个人发展跟其他人轨迹绑定
  - timing 原则 — 同事件不同年龄影响不同
  - chronosystem(Bronfenbrenner Ch 14)— 历史时段决定育儿可能空间
- **传统"我妈那时候你怎么怎么"= 不分 chronosystem 立场**
- **处理**:V1 立场 — 2026 年育儿 ≠ 1995 年育儿 (chronosystem 不同)。选择性继承传统,不直接套老经验。
- **涉及卡片**:C-S0-1529, C-S0-1530, C-S6-1509, C-S8-1134
